# 독락당 디지털 아카이브

공개 주소: https://dhryu60.github.io/

첫 화면은 독락당의 네 주제(논어와 공자, 두시언해, 과학과 사유, 오래된 질문들)를 연결합니다.
기존 기술 블로그 목록은 `/blog/`에 있으며, 기존 게시글·태그·카테고리 주소와 이슈 기반 발행 기능을 유지합니다.
GitHub Pages는 `main` 브랜치 루트의 Jekyll 빌드로 배포됩니다. `index.html`은 아카이브, `blog.md`는 블로그 목록입니다.

배포 파일에는 비공개 보관 폴더, 초안 JSON, Sites 인증·설정 파일을 포함하지 않습니다.
원래 음원 출처와 비상업적 사용 라이선스 표시는 각 자료 화면에 유지합니다.

```text
