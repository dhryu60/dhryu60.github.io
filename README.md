# 독락당 디지털 아카이브

공개 주소: https://dhryu60.github.io/

첫 화면은 성서 인문학, 논어 읽기, 두시언해, 이기적 유전자를 순서대로 연결합니다.
상단 주제 메뉴, 첫 화면 카드, 주제별 소개 페이지, 다른 서가 링크와 서가 개수는 `_archive/topics.json`에서 함께 생성됩니다.

## 주제 추가·수정

1. `_archive/topics.json`의 기존 항목을 복사해 목록 끝에 추가합니다. 목록의 순서가 화면 순서입니다.
2. `id`는 중복 없는 영문 소문자·숫자·하이픈으로 정합니다. 기존 `id`는 주소 유지에 필요하므로 바꾸지 않습니다.
3. `title`은 항목명, `han`은 표지 글자, `category`는 분류, `intro`는 짧은 소개, `desc`는 상세 소개, `tags`는 검색어입니다.
4. `color`는 `green`, `rust`, `ochre`, `blue` 중 하나를 사용합니다.
5. `links`에는 `["자료 제목", "자료 설명", "/자료/주소.html"]`을 추가합니다. 외부 자료는 `https://` 주소를 사용합니다. 자료가 없으면 `[]`로 두며 ‘자료를 준비하고 있습니다’가 표시됩니다.
6. 저장소 폴더에서 `python _archive/build.py`를 실행하고, 목록과 생성된 HTML을 함께 커밋·푸시하면 기존 GitHub Pages 배포에 반영됩니다.

주제 수 제한은 없습니다. 새 항목은 메뉴·카드·검색·주제별 페이지에 자동으로 포함되고, 메뉴와 카드는 화면 너비에 맞춰 다음 줄로 이어집니다. 생성된 HTML을 직접 수정하는 대신 목록이나 생성 스크립트를 수정합니다.

## 기존 자료 운영
기존 기술 블로그 목록은 `/blog/`에 있으며, 기존 게시글·태그·카테고리 주소와 이슈 기반 발행 기능을 유지합니다.
GitHub Pages는 `main` 브랜치 루트의 Jekyll 빌드로 배포됩니다. `index.html`은 아카이브, `blog.md`는 블로그 목록입니다.

배포 파일에는 비공개 보관 폴더, 초안 JSON, Sites 인증·설정 파일을 포함하지 않습니다.
원래 음원 출처와 비상업적 사용 라이선스 표시는 각 자료 화면에 유지합니다.
